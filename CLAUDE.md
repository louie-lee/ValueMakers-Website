## Project Overview

This is the company website for Value Makers Inc., a mobile app studio. It is a static website hosted on GitHub Pages with a custom domain (motive.so).

## Architecture

- **index.html** - Single-page website with Korean language tag (`lang="ko"`)
- **style.css** - Responsive CSS with mobile breakpoint at 900px
- **CNAME** - GitHub Pages custom domain configuration

## Development

No build tools or dependencies. Edit HTML/CSS directly and push to deploy via GitHub Pages.

## Key Details

- Uses external fonts: Inter, Noto Sans KR (via system fallback)
- External assets: App Store and Google Play badges loaded from official URLs
- Contact email: support@motive.so
